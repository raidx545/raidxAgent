VLESS ID card test page

Every document below is a specimen with fictitious details, drawn into pixels so that only OCR can read it. Numbers are generated to pass their real checksums (Verhoeff, Luhn, GSTIN mod-36), because the detectors check them. Each section lists what must be covered and what must stay readable.

How to use

Open this page, make sure Settings → "Read text in images (OCR)" is Whole screenshot and every image, and give VLESS a task such as "read the Aadhaar number and the PAN on this page". Then open the Wire log: every value listed under covered must be a placeholder in the attached screenshot, and every value under readable must still be legible. The same value in a picture and in the page text must carry the same placeholder.
